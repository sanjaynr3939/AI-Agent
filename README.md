# 🤖 AI Agent

A modular AI Assistant built with Python.

## Features

- Greeting
- Time
- Date
- Day
- Memory
- Calculator
- CSV Analysis
- Department Filtering
- Web Search
- Gemini AI Integration

## Technologies Used

- Python
- Pandas
- SQLite
- Google Gemini API
